#### WR-461. `N_FillNSidedHole` lets a corner patch cross the tangent plane of a neighbouring face, so a fillet setback corner bulges past the faces it meets (#1170)
- **Severity:** Wrong result
- **Area:** Blends
- **Location:** `source/SMLib/src/NL_SrfAdv.cpp`, `N_FillNSidedHole` (reached through `SmFilletCorner::CreateCornerPatch`, `SmBSplineSurface::CreateCornerBlend`, `SmBSplineSurface::CreateNSidedPatch`): the cross-boundary derivatives across the inner curves ("Adjust derivative magnitudes") take the speed of the neighbouring boundary half curves, whatever the width of the quadrilateral they cross.
- **What happens:** each of the patch's quadrilaterals is a bicubic Coons patch. Across it, the height above a neighbour's tangent plane is a cubic Bezier with control heights `0, 0, D - dv m / 3, D` (`D` the height of the opposite inner curve, `m` the normal component of the cross derivative there, `dv` the parameter length). The derivative's length grows with the boundary curves (the setback), while `D` is fixed by the rounds' radius, so once `m > 3 D / dv` the third control height changes sign and the patch leaves the neighbour's plane to the wrong side before it turns back.
- **Trigger:** a box 60 x 40 x 20 with r5 rounds on the three edges at (60, 40, 20) and a setback `s` on that corner (`SmFilletCorner::SetSetBackDist(s)` between `CreateFilletCorners` and `DoFilleting`; the setback itself needs WR-445). The tight bounding box maximum exceeds the box on every axis by 0 for `s <= 10`, 0.0021 for 11, 0.0298 for 12, 0.0806 for 13 and 0.2515 for 15.
- **How found:** SolidCraft's setback corner test through the fork's `smlib_blend_setback` (tangency-labs/solidcore#1170).
- **Confirmed:** yes, the issue's table is the fork's C++ result and the Rust port reproduces every value (test `upstream_bulges_past_the_faces_for_a_large_setback`).
- **Fix:** none in the fork yet. The Rust port has its own, below.
- **Rust port:** `fill_n_sided_hole` behaves as upstream by default. With `Kernel::fixes.corner_blend_stays_inside_neighbours` (`create_n_sided_patch_with`, `fill_n_sided_hole_with`), `limit_inner_cross_derivs` shortens each inner-curve cross derivative, control point by control point (the end points keep the corner values), so that the third control height keeps at least a fifth of `D`; the direction, so G1, is unchanged. Test `a_setback_patch_stays_inside_the_box_with_the_fix`: the bounding box is the box's for `s` in 8, 10, 11, 12, 13 and 15, with 21 faces and a manifold solid.
